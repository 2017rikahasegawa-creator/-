Excelの「CSV出力用データ」シートの表（または「メンバー表入力」シートの選手一覧）をコピーして、下の枠に貼り付けてください。

🔄 指名打者（DH）の解除

指名打者を解除して10人出場から通常の9人出場へ移行します。どちらのパターンか選択してください。

📱 アナウンス担当のスマホ・タブレットへ引き継ぎ

パソコンで入力したスタメン・控え・審判データを、アナウンス担当のお母様のスマホやタブレットへ引き継ぎます。

方法A：共有URL・QRコードで送る（データの入ったURLを発行）
※Web上（Google Apps Script / GitHub Pages等）に公開している場合、下のURLまたはQRコードを送るだけで、スマホで開いた瞬間に全データが反映されます。
📷 スマホのカメラで読み取って開く（ネット接続時）
方法B：Googleドライブ・LINE用「データ埋め込み済みファイル」を出力
⚠️ Googleドライブは仕様上、通常のURL共有だけだと中身がリセットされますが、下のボタンで「今のスタメンデータが最初から埋め込まれた専用HTMLファイル」を保存してGoogleドライブやLINEに置けば、お母様がスマホで開いた瞬間に全メンバーが入った状態で使えます！
方法C：LINE・メールで「引き継ぎ呪文（文字コード）」を送る／読み込む
すでにスマホ側にこのツールが入っている場合は、「引き継ぎコードをコピー」してLINEのトークで送り、スマホ側で下に貼り付けて「復元」を押すだけでも一瞬で同期できます。
